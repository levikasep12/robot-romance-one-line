A single one-line pickup line aimed at an AI, generated by a tiny deterministic program: a transformer pun — the architecture behind modern language models, and "attention" its core mechanism — so the flirt speaks in the machine's own vocabulary.

## Run it

```sh
python3 main.py
```

It writes one pickup line (59 characters) to `/output/entry.txt`. Standard library only, no network, no input files, and the same bytes on every run from any working directory.
